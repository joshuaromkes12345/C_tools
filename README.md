# Instructie COP (commandline output printer)

Compile het programma. ``gcc main.c -o main.out``

dan als je het main.out genoemd hebt. ``./main.out <JE_BESTANDSNAAM>`` dan leest hij je bestand uit.

# Instructie CTI (commandline text inserter)

Compile het programma. ``gcc main.c -o main.out``

dan als je het main.out genoemd hebt. ``./main.out <JE_BESTANDSNAAM>`` dan krijg je een kniperende cursor. Dan kunt uw gewenste dingen uittypen

om het programma te beeindigen moet u op een lege line ``END`` invullen.
